Agent Design — Deep Dive

🏷️ Classifier Agent

Categorizes feedback into 11 types: packaging, side_effects, effectiveness, pricing, delivery, customer_service, taste_texture, product_quality, positive_feedback, and more.

Output: category, urgency (1-5), requires_immediate_action

💭 Sentiment Analyzer

Goes beyond positive/negative — detects nuanced emotions (joy, frustration, anger, trust), extracts key phrases, assigns confidence-weighted scores.

Output: score (-1.0 to +1.0), emotions, key_phrases

🔍 Entity Extractor

Identifies products, SKUs, competitor brands, ingredients, specific issues mentioned, and customer suggestions.

Output: products, competitors, ingredients, issues, suggestions

🧠 Orchestrator

The "brain" — synthesizes outputs from all 3 agents, determines action priority, detects cross-brand relevance, generates recommended actions.

Output: summary, action_required, recommended_action, cross_brand
